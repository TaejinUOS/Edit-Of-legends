## 자동 검증

- 이벤트 판정·컷 계획·수동 트림, API 인증과 저장, Premiere 어댑터의 SDK 모형 테스트를 실행한다.
- 실제 녹화본의 120초(0/0/0), 130초(0/0/0), 600초(0/0/1), 1515초(7/2/7), 1740초(7/3/7)를 OCR 회귀 테스트에 포함했다. 마지막 HUD도 시각 확인했다.
- 행 단위 판독의 신뢰도가 낮으면 글자별 판독으로 보완한다. Tesseract PSM을 문자열로 전달할 때 0이 누락되는 현상을 재현하여 숫자 타입으로 고정했다.
- 10초 이내 후속 연속 판독이 이전 값을 뒷받침하면 일시적 상승/하락 오인식을 기준값에 반영하지 않는다. 지속적인 감소는 경고 후 자동 확정을 중단한다.
- 실제 미디어 API 통합 테스트: 프레임 미리보기, HTTP 206 부분 재생, 짧은 구간 분석, 캐시 재사용, 분석 취소.
- `npm test`: 26개 통과, 실패/건너뜀 0개. `npm run check`: JavaScript 15개 및 UXP manifest 검사 통과. 의존성 보안 검사: 발견된 취약점 0개.
- Windows x64 설치 프로그램을 빌드하고 사용자별 설치를 통과했다. 등록된 런처가 번들 Node.js를 창 없이 실행하고, 번들 FFmpeg/ffprobe를 사용하는 엔진 0.2.0의 인증된 `/api/health` 응답을 확인했다.
- `.ccx` 0.2.0을 UPIA로 설치하여 Premiere Pro 확장 목록의 Enabled 상태를 확인했다. UXP의 최초 외부 프로세스 동의 창과 패널에서의 자동 호출은 실제 UI 검증이 남아 있다.
